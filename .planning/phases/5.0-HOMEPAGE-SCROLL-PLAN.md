## 2. 🏗️ Winston — 架構現況與調整建議

*2026-07-02 CST*

### 2.1 現況診斷

```
app/(site)/page.tsx
├── ScrollStoryRoot          ← Phase 4 原型（void/hand/manifesto/portal）
└── 舊 Cohere 區塊 ×6        ← TrustBar、pillars、case study、process、testimonial、blog/projects、CTA
```

**問題**：雙軌首頁 — 上方沉浸式 scroll-story，下方傳統 marketing 區塊。品牌語言、動效節奏、資訊密度不一致。使用者滾過 Hero 後落入舊 Phase 2.3 UI，CI 斷裂。

**架構判斷**：

| 維度 | 現況 | 建議 |
|------|------|------|
| 首頁職責 | 形象 + 預覽 + 轉換混雜 | **單一 scroll 敘事軸**，各 section 職責清晰 |
| 元件邊界 | `scroll-story/` vs `page.tsx` inline | 新根 `home-scroll/` 或擴展 `scroll-story-root` |
| 3D 範圍 | 僅 Hero pin | R3F Canvas **限 Hero section**；其餘 CSS/GSAP |
| 內容來源 | 硬編 + i18n 混用 | `lib/content/home-sections.ts` 統一 |
| 效能 | Three + Framer 雙 motion 庫 | Hero=R3F+GSAP；section=reveal 用 GSAP 或 CSS only |
| 路由 | 內頁完整 | 首頁 = **摘要 + CTA 深連**，不重複內頁全文 |

### 2.2 建議架構

```
components/home/
  home-scroll-root.tsx          # 單一根元件，取代 page.tsx 區塊拼裝
  sections/
    section-hero.tsx            # R3F Co-Hero Cradle（CI 錨點）
    section-about.tsx           # StoryAboutMe 章節 pin/scrub
    section-lab.tsx             # Velite projects 精選
    section-services.tsx        # 四服務柱
    section-blog.tsx            # posts 精選 + 心法摘要
    section-booking.tsx         # Cal.com embed
  three/
    hero-co-hero-scene.tsx      # 沿用/重構 design-lab 成果
lib/content/
  home-sections.ts              # 各 section 中英文案
  home-story-chapters.ts        # About 章節（源自 StoryAboutMe）
```

### 2.3 技術決策（LOCKED 建議）

| 決策 | 選擇 | 理由 |
|------|------|------|
| Scroll 驅動 | GSAP ScrollTrigger | 已整合；pin/scrub 成熟 |
| Hero 3D | R3F dynamic import | bundle 隔離 |
| Section 過場 | GSAP `ScrollTrigger.batch` + CSS `clip-path`/`mask` | 時尚、可控、非過度 3D |
| 資料 | Velite `posts` / `projects` slice | 不新建 CMS |
| i18n | `home-sections.ts` + 既有 `t()` | 漸進遷移 |
| 移除 | `page.tsx` 內 TrustBar/Testimonial/ProcessSteps | 與新敘事衝突 |

## 3. 🎨 Sally — UX 建議與互動設計

*2026-07-02 CST*

### 3.1 使用者旅程（首頁單頁）

> **進站 3 秒**：看見手托 Logo — 「這是誰、什麼調性」  
> **滾動 30 秒**：讀到三要点 — 「他能幫我什麼」  
> **滾動 2 分鐘**：故事 + 作品 + 服務 — 「可信、有深度」  
> **底部**：預約 — 「低摩擦開始對話」

### 3.2 六 Section IA（使用者指定 + UX 潤飾）

| # | Section | 目的 | 核心內容 | Scroll 過場建議 |
|---|---------|------|----------|-----------------|
| **1** | **Hero** | 吸睛、建立 CI、傳三要点 | Logo + Motion；架構先行 / AI 導入 / 體驗落地 | **Pin 全屏**；手×Logo 同掃顯影；scrub 時三柱 stagger 浮現；底部 scroll indicator |
| **2** | **About Me** | 講故事、建立信任 | `StoryAboutMe.md` → 6 章（見 §3.3） | 章節 **horizontal snap** 或 **vertical pin + 文字 crossfade**；肖像 parallax |
| **3** | **Lab** | 證明能力 | 3 精選 case study（大圖 + 一句） | 卡片 **stagger reveal**；hover 線框 glow |
| **4** | **Service** | 說明可提供什麼 | 程式架構諮詢 · 網站開發 · 設計包案 · 整體資訊規劃 | 四柱 **typography scrub**；icon 線框描邊動畫 |
| **5** | **Blog** | 心法、思想領導 | 2–3 篇精選 + 「更多」→ `/blog` | 編輯排版 reveal；標題 letter-spacing 微動 |
| **6** | **Booking** | 轉換 | Cal.com 30 分鐘 embed | 信任一句 + embed **fade up**；sticky CTA 可選 |

### 3.3 About 章節化（源自 `docs/StoryAboutMe.md`）

| 章 | 標題（潤飾） | 原文錨點 | 情緒 |
|----|-------------|----------|------|
| Ch1 | 自學驅動 | 藝術比賽 → 生醫 → 找熱情 | 探索 |
| Ch2 | 交大轉折 | 基因定序 → 第一個全端案 | 覺醒 |
| Ch3 | 替代役淬鍊 | 1914 品牌、Chatbot、Heroku | 實作 |
| Ch4 | 後端與電商 | SLA、藍綠部署、SaaS、雲端 | 專業 |
| Ch5 | 架構觀 | 自由接案、UI/UX、長期價值 | 信念 |
| Ch6 | 工作之外 | 合唱、飛輪、平衡 | 人味 |

**UX 原則**：每章 1 屏可讀；不堆履歷 bullet；用 **一個畫面一句話** 推進敘事。

### 3.4 Hero Section — CI 設計重點（最高優先）

**第一畫面（0–3s 自動）** — 沿用 R3 方案 A「托舉顯影」：

1. 黑場 → 手+Logo 頂點雲（同一團）
2. #05 掃描線自下而上 — **同時顯影**
3. Logo 三層 snap 對位於掌心
4. 手指微收 — 「握住」

**Scroll 後（Hero pin 內）**：

- 三要点以 mono label + 大標 **stagger** 出現（非舊式四欄 card）
- 微文案：「往下滾動，認識 8plus」+ 動態 scroll cue
- 手可向前遞出 Logo（Reach 精簡版），作為過渡至 About 的視覺橋

**禁止**：粒子、aurora、右側白邊、首屏大段段落字。

### 3.5 全頁過場語言（統一）

| 過場類型 | 用於 | 規格 |
|----------|------|------|
| `pin + scrub` | Hero、About 章 | progress 0→1 驅動 uniform |
| `stagger reveal` | Lab、Service、Blog | `y: 24→0`, `opacity`, `0.05s` 間隔 |
| `clip-path wipe` | Section 邊界 | 上→下 2–4% 視差 |
| `crossfade` | About 章切換 | 0.4s ease |
| `reduced-motion` | 全站 | 靜態排版，無 pin |

### 3.6 導覽與進度

- 右側 **section dot**（6 點）：Hero · Story · Lab · Service · Blog · Book
- 與主 nav 呼應但不重複（nav = 站內頁；dot = 首頁內錨點）
- Booking section 可選 **sticky「預約 30 分鐘」** 浮動鈕（滾過 Hero 後出現）

| D2 | 首頁 Lab 顯示幾件？ | **3 件** — 一主二副 |
| D3 | Blog 顯示全文還是摘要？ | **摘要 + 金句 pull quote** |

## 4. 首頁資訊架構（LOCKED 草案）

### 4.1 總體

- **形式**：單頁垂直 scroll，約 `400vh–550vh`（依 About 章數調整）
- **節奏**：Hero 最重（~120–150vh pin）→ About 次重 → 其餘 reveal
- **CTA 主路徑**：Hero scroll cue → … → Booking embed
- **CTA 次路徑**：各 section「查看更多」→ 對應內頁

### 4.2 Section 規格摘要

#### §1 Hero（CI 錨點）

| 項目 | 規格 |
|------|------|
| 視覺 | 滿版 R3F：手托 Logo 線框 + 同掃顯影 |
| 文案 | 三要点：架構先行 / AI 導入 / 體驗落地 |
| 技術 | `hero-co-hero-scene.tsx` + GSAP pin |
| 資產 | `hand_line.png`、`logo-wireframe.ts`、`co-hero-phases.ts` |

#### §2 About Me

| 項目 | 規格 |
|------|------|
| 來源 | `docs/StoryAboutMe.md` → `lib/content/home-story-chapters.ts` |
| 呈現 | 6 章 vertical pin 或 stacked reveal |
| 視覺 | 肖像（`public/me/`）+ 章標題 typography |
| 深連結 | `/about` 全文 |

#### §3 Lab

| 項目 | 規格 |
|------|------|
| 資料 | `getLocalizedProjects(locale).slice(0, 3)` |
| 呈現 | 策展大圖卡片；Case Study 標籤 |
| 深連結 | `/lab`、`/lab/[slug]` |

#### §4 Service

| 項目 | 規格 |
|------|------|
| 四項 | 程式架構諮詢 · 網站開發 · 設計包案 · 整體資訊規劃 |
| 呈現 | 四柱大標 + 一句描述 |
| 深連結 | `/services` |

#### §5 Blog

| 項目 | 規格 |
|------|------|
| 資料 | `posts` 精選 2–3 篇 |
| 調性 | 心法、內在思考 — 非純技術教程列表 |
| 深連結 | `/blog`、`/blog/[slug]` |

#### §6 Booking

| 項目 | 規格 |
|------|------|
| 功能 | Cal.com 30 分鐘會議 embed |
| 信任鋪墊 | 一句 + 可選 testimonial 單則 |
| 備援 | `/booking` 完整頁 |
