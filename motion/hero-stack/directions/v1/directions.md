## A · Stack Diagram
- language: system-diagram（平面）· 參考：Vercel／Stripe 的基礎架構解說片
- Logline：七層由下往上一層層點亮，一顆淡綠色封包沿著主幹往上跑；到 Agent 那層開始循環 plan → tool → check，最後頂層的 AI Apps 亮起，畫面收回 8plus logo。
- Feel：連續推進，每 2.5 秒點亮一層；鏡頭推近目前這一層，最後拉遠看到整座堆疊。
- Risk：版面接近資訊圖表，比較穩，驚喜感較低。

## B · One Frame, Seven Lives（推薦）
- language: continuous-morph · 參考：Linear changelog、Rauno 的形變短片
- Logline：首頁原有的淡綠「對焦框」就是主角。框裡的內容一路形變：品牌網站 → API 膠囊 → 資料表 → 架構樹 → 語音轉錄 AI → Agent 循環 → 三個真實作品，最後收成 8plus logo，再回到第一幀，形成循環。
- Feel：一鏡到底，每一拍都有變化；底部的進度軌道標出目前在哪一層，右下角大字（Frontend. → AI.）跟著換。
- Why：延續首頁現有的「Focus」語彙，和左邊的文案最一致。
- Risk：形變的時間點要抓得準，做得不好會像在切投影片。

## C · Exploded Stack（3D）
- language: depth / interface in space · 參考：Apple 發表會的爆炸分解圖
- Logline：七層真實介面像建築樓層一樣在空間裡疊起來。鏡頭從 Frontend 底層掠過、一路往上升到 AI Apps，再環繞拉遠；最後所有樓層壓平，收成 logo。
- Feel：一個連續的 3D 鏡頭運動，最有份量感。
- Risk：截圖是斜著看的，裡面的細字讀不清楚，只看得到層次結構。
