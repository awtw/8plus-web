## 0. 問題診斷

| 舊方針問題 | 使用者感受 |
|------------|------------|
| Logo = 2D 實心 SVG / 粒子聚合（Canvas 2D） | 與 #05 #13 線框未來感 **斷裂** |
| 手 = procedural 低 poly，與 logo 無關 | 不像 8plus，像 generic 3D demo |
| Ch0 Logo → Ch1 換成手 | **主視覺主角換人**，品牌錨點丟失 |
| `hand_line.png` 僅美術參考 | 未進入識別系統 |
| Design Lab 三欄 vs 首頁兩套系統 | 無法當真實上線預覽 |

**結論**：主視覺只能有 **一條幾何語言** — Logo 幾何（雙圓 + 斜切）全程是主角，線框手是 Logo 的 **敘事延伸**，不是第二個 IP。

## 1. 新核心概念 —「Wireframe Mark」

> **8plus 首頁主視覺 = 同一顆 Logo 的三種物質狀態：虛空 → 掃描顯影 → 伸手協作**

| 狀態 | 視覺 | 你喜歡的技術 |
|------|------|--------------|
| **S0 Void** | 純黑；無實心色塊 | — |
| **S1 LiDAR** | Logo **線框** 被掃描線顯影 | #05 |
| **S2 Reach** | Logo 斜切線 **延伸** 為 `hand_line` 伸手姿態 | hand_line 參考 |
| **S3 Handshake** | 雙手線框交握；**掌心之間浮現實心 Logo**（蓋章） | #13 |
| **S4 Seal** | 實心 Logo snap 回穩定；進 Manifesto | Share 頁 snap 語彙 |

**一句話**：不是「先看 Logo 再看手」，是 **「Logo 從掃描中誕生，長出手，與你握手，再蓋章定型」**。

## 2. Logo 主視覺長什麼樣（靜態錨點）

### 2.1 保留不變（CI 鎖定）

- 語意：小圓 + 大圓 = 8；斜線 = plus
- 比例：`viewBox 0 0 100 100` 現有 path
- 色：dark 底 + `#f8fafc` 線 / `#38bdf8` accent 掃描帶

### 2.2 必須改變（主視覺層）

| 舊 | 新 |
|----|-----|
| 實心 fill SVG | **線框 mesh**（圓周 + 斜線稜邊分段） |
| 粒子採樣 logo | **邊緣頂點 + 內部經緯線**（像 hand_line 密度） |
| Cinema 光帶背景 | **純黑 + 極淡網格**（mono 0.06 opacity） |
| 滿屏藍粒子 | **禁止**（CI 禁用 AI slop） |

### 2.3 Logo 線框規格

```
圖層 L1：小圓 — 24–32 邊 wireframe 圓
圖層 L2：大圓 — 32–40 邊 wireframe 圓
圖層 L3：斜切 — 雙平行邊 + 對角經線 8–12 條
材質：1px 白線；掃描帶過處 accent 藍 1.5px
```

靜態海報幀 = `hand_line` 同款 **白線黑底**，但輪廓是 **8plus 符號** 不是手掌。

## 3. Scroll 敘事（修訂六章）

總高 ~650vh；**單一 R3F Canvas** 全程 pin 背景，DOM 文案疊加。

| 章 | ID | Scroll | 畫面（使用者看到的） |
|----|-----|--------|----------------------|
| **Ch0** | Void | 0–12% | 黑；極小 mono `8PLUS.APP` |
| **Ch1** | Scan | 12–35% | **#05 掃描 Logo 線框**（非手）自下而上顯影 |
| **Ch2** | Reach | 35–55% | 大圓 + 斜線 **morph** 為 hand_line 伸手；小圓留左上像衛星 |
| **Ch3** | Handshake | 55–82% | **#13** 第二隻手入場交握；交點 **實心 Logo 蓋章** 0.8s |
| **Ch4** | Manifesto | 82–92% | 線框淡出；實心 Logo 角標 + 三柱 A/B/C |
| **Ch5** | Portal | 92–100% | 六入口；Logo 小角標常駐 |

### Ch1 vs 舊 Lab #05 差異

- Lab：掃描 **手**
- 上線：**掃描 Logo** → 品牌 3 秒內被記住

### Ch2 hand_line 怎麼接

- **不是**貼 `hand_line.png`
- 斜線頂點 lerp → 手指骨架；大圓 → 掌心；小圓 → 腕部關節
- 美術：以 `public/plants/hand_line.png` 調 **比例與線密度**，非貼圖

### Ch3 蓋章（建議鎖定）

- 交握 climax：`progress > 0.88`
- 雙手間 **實心 fill Logo** scale 0→1 + snap（沿用 Share `share-hub-logo` 語彙）
- 情緒：協作完成、信任印章

## 6. 技術方針（Winston 對齊）

```

components/home/three/
  hero-mark-scene.tsx           # 單一 Canvas，uPhase 驅動
```
