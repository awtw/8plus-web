# R Analysis — 購物車按鍵影響因素分析

## 截圖
![R Analysis Web](/og/labs/r-analysis/web.png)

**Tags**: R, VanillaJS

利用 R 建立分析模型，探討購物車按鍵設計對購買轉換的影響，並配合 VanillaJS 進行互動式視覺化，輔助決策與迭代。

## 重點
- 模型假設與變數選擇
- 實驗設計與 A/B 比較
- 視覺化呈現與洞察整理

## 分析一：購物車按鍵顏色與購買行為
以不同國家與裝置的資料，比較兩組購物車按鍵顏色是否影響購買，並觀察文化與裝置差異造成的行為不同；以 boxplot、時間序列線圖與密度曲線做視覺化比較。

## 分析二：慢性腎臟病（CKD）與正常人的腸道菌相差異
以 16S rRNA 定序資料做 clustering 並產生 OTU table（每個 OTU 代表一種細菌），用 PCA、PCoA 比較兩組菌相距離；再看菌屬之間的相關性，最後比較選定菌屬在兩組的相對豐度差異。
