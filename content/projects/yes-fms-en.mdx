# YES Financial System — Fund Analytics & Data Pipeline

![YES fund overview](/og/labs/yes-fms/web.png)

**Tags**: Next.js, TypeScript, Supabase, Cron, Vercel

## Why
Advisers explaining policy-linked funds to clients kept jumping between fund-house sites, MoneyDJ and spreadsheets. The deeper problem was unsynchronised sources: funds, ETFs, stocks and indices trade on different days, so fetching live in the browser or mixing sources breaks charts, makes dividend figures disagree and leaves performance unauditable.

YES moves collection, field mapping and source-value storage into back-end cron jobs, leaving the front end to present and explain. (The UI is in Traditional Chinese.)

## Features
- **Fund overview**: filter by 20-plus fund houses (Allianz, BlackRock, PIMCO, JPMorgan, Schroder, CTBC and more) and search; shows cumulative return, CAGR, annualised dividend yield and max drawdown, with NAV charted against the S&P 500 and TAIEX.
- **Dividend cash flow**: enter units held to see per-unit payouts, annualised yield and estimated cash per ex-date, listing both the source yield and the formula yield.
- **Investment simulator**: lump sum or monthly, 1–40 years, growth from the fund's historical CAGR or conservative / aggressive scenarios, up to five comparison funds, and a printable proposal.
- **Member CRM**: Supabase-backed members with status (active / lead / inactive), owner, channel, notes and linked funds.

## Data pipeline (Pipeline Observatory)
A dedicated page explains where data comes from, how it is judged and how often it refreshes, labelling what runs today versus what is still spec (LIVE / HYBRID):

1. **Source master and whitelist**: the fund whitelist and universe bootstrap decide which funds, ETFs, stocks and indices to track.
2. **Core fund sync**: MoneyDJ for fund NAV and dividends, Yahoo for required ETFs; name normalisation plus verified code overrides pick the most trustworthy match, with a 0.82 score threshold.
3. **Expansion instruments**: candidates are written to instruments and a source map, then Yahoo daily bars fill daily NAV.
4. **Status write-back**: each instrument records ok / partial / failed / pending, last success time and failure reason, read directly by the dashboard and pipeline page.
5. **Formulas and performance**: the annualised-yield formula is live; the authoritative adjusted-NAV and CAGR batch is still planned.

The page reads Supabase report snapshots (last sync, success and failure counts, instruments to investigate and why), all read-only.

## Tech
- Front end: Next.js + TypeScript, dark dashboard UI, hosted on Vercel
- Database and auth: Supabase (funds, NAV, dividends, instrument master, source map, sync status, members and notes)
- Collection: scheduled crawlers (`crawl:required-real`, `sync:universe-instruments`, `crawl:universe-daily`) over MoneyDJ and Yahoo Finance
- Quality: dividend-formula reconciliation, sync report snapshots, daily checkpoints (batch size and lookback window)

## Limitations
- Old and new schemas run side by side during migration; some charts still read the legacy tables and add the new status fields.
- The authoritative adjusted-NAV and CAGR batch isn't live yet; performance uses existing NAV.
- Sign-in required; figures are for internal analysis and client conversations, not investment advice.
